# Application & DevSecOps Pipeline Documentation

## 1. Nama Aplikasi & Fungsi
**Nama Aplikasi:** Filament Management App  
**Fungsi:** Aplikasi berbasis web untuk pengelolaan data administratif dan dashboard menggunakan ekosistem Laravel dan Filament PHP Framework. Aplikasi ini menyediakan antarmuka manajemen data yang interaktif dan responsif.

## 2. Bahasa & Framework yang Digunakan
- **Programming Language:** PHP 8.x
- **Framework:** Laravel
- **Admin Panel Framework:** Filament PHP
- **Database:** MySQL / MariaDB
- **Package Manager:** Composer & NPM
